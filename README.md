# employe-crud-app-frontend

Frontend for the Employee Directory CRUD Application built with React, TypeScript, and Vite.

## Features
- Add, View, Edit, and Delete employee records
- Search filtering by name, email, or role
- Pagination (5 employees per page)
- Responsive UI for desktop and mobile
- Axios integration for REST API communication

## Setup & Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.
   Ensure the backend server is running on `http://localhost:5000`.
